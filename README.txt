FitFuel PWA v2

This is a real Progressive Web App package. Host this folder at an HTTPS URL, then open that URL on iPhone Safari.
On iOS 26, Safari supports adding websites as web apps; for the intended PWA experience, use Share -> Add to Home Screen -> Open as Web App -> Add.

Files:
- index.html
- manifest.json
- sw.js
- icons/

The app stores workout completion, check-ins and settings in browser local storage and includes JSON backup/restore.
